REF: ED101 Engineering • Cloud Platform Can Tho Campus / Hybrid (Can Tho & Remote) High Priority

Senior Learning Platform Engineer

Reports directly to: Principal Cloud Architect

Salary: $145,000 – $168,000 AUD (~2.3B – 2.7B VND/yr) + 11.5% Superannuation / Benefits

Role Overview

As a Senior Learning Platform Engineer, you will build and maintain core services for our learning system, ensuring high performance and reliability for students and teachers.

Key Responsibilities

  1. Develop backend web services using Golang, TypeScript, and Docker.
  2. Optimize database performance using PostgreSQL and Redis.
  3. Work with Frontend Developers to create REST and GraphQL APIs.
  4. Set up automated testing and continuous deployment pipelines.
  5. Monitor system health and troubleshoot operational issues.

Candidate Requirements & Qualifications

Essential Requirements:
  • Bachelor's degree in Computer Science, Software Engineering, or equivalent industry experience (5+ years).
  • Experience with backend development in Go, Node.js, or Java.
  • Good knowledge of SQL databases and REST APIs.
  • Familiarity with Git and basic Linux operational commands.
Highly Desirable & Preferable Qualifications:
  • Previous experience working with EdTech applications or LMS..
  • Basic knowledge of cloud platforms like AWS or Google Cloud.
  • Familiarity with ISO 27001 compliance standards, GDPR, and Vietnamese personal data protection regulations (Decree 13/2023/ND-CP).

REF: UX204 Design & Product Can Tho / Ho Chi Minh City High Priority

Accessibility UX Designer

Reports to: Design Team Lead

Salary: $120,000 – $138,000 AUD (~1.9B – 2.2B VND/yr) + 11.5% Superannuation / Benefits

Role Overview

We are looking for a UX Designer to help us build user-friendly and accessible interfaces for everyone, including users with disabilities.

Key Responsibilities

  1. Conduct user testing and interviews with various user groups.
  2. Design wireframes, prototypes, and UI components in Figma.
  3. Ensure web designs follow web accessibility guidelines (WCAG).
  4. Collaborate closely with developers during implementation.
  5. Share UX and accessibility best practices with the team.

Candidate Requirements & Qualifications

Essential Requirements:
  • 3+ years of experience in UI/UX design for web applications
  • Proficiency in Figma and wireframing tools.
  • Basic understanding of web accessibility standards (WCAG).
  • Strong communication and teamwork skills.
Highly Desirable & Preferable Qualifications:
  • IAAP Certification (such as CPACC or WAS credential).
  • Fundamental working knowledge of semantic HTML5, modern CSS3 layout techniques, and browser rendering engines.
  • Experience conducting cognitive load and readability assessments for educational materials.
